Can I use Atlas for my own company today?

Not yet. Atlas is invite-only while Pro gets ready. You can use the full demo now and join the waitlist to hear first.

Can the AI see documents I’m not allowed to read?

No. Every passage carries its company, departments and public flag, and the database filters on them before anything is ranked. The AI only ever receives text the asker may read. The test set has found 0 leaks in every run.

What happens when the answer isn’t in my documents?

Atlas checks that the passages it found really answer the question. If they don’t, it says it couldn’t find it instead of guessing.

Which files can it read?

PDF, Word and Markdown. Each document is split into passages you can inspect in the library, and older versions of a document are ranked down.

What does the website chat bubble see?

Only the documents you mark public. It works on the websites you allow, with rate limits, and the bubble never reaches private files.

Does it understand Hindi?

Yes. Ask in English, Hindi or Hinglish and Atlas replies in the same language, with the same sources.

Can I see how it is built?

Yes. The source code and the test results are on GitHub.
