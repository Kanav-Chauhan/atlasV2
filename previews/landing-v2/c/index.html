Ask in plain words.

English, Hindi or Hinglish. The permission filter runs inside the search, before ranking, so the AI never reads a passage the person can’t open.

“How many days of earned leave can I carry forward?”

  1. GuardStops prompt tricks and abuse.
  2. Route“Hi” gets a hello. Only real questions search.
  3. RewriteUses the chat so far, and turns Hindi into an English search.
  4. SearchMeaning and keywords together, only in documents this person may open.
  5. Re-rankThe best passages go first. Superseded versions drop.
  6. CheckDo these passages really answer it? If not, try once more, then say “Not found”.
  7. AnswerStreamed, with numbered citations checked on the server.

Questions, answered.

Can someone read a document they shouldn’t?

No. Every passage carries its company and department, and the search filters by the person’s access before anything is ranked. The AI never sees text the person can’t open. The leak test has found 0 leaks in every run.

What if the answer isn’t written down?

Atlas says “Not found in your documents” instead of guessing. On the website, the bubble asks the visitor to contact the company.

Which files can I upload?

PDF, Word, Markdown and plain text. You can see how each one was split into passages, and older versions marked as replaced are ranked down.

Can my team ask in Hindi?

Yes. Ask in Hindi or Hinglish and Atlas understands the question, searches your documents and answers with the same citations.

What can the website chat see?

Only the documents you mark public. It runs only on the websites you allow, with rate limits, so a visitor never reaches staff documents.

Where do my documents go?

Files are stored, split and searched on Atlas’s own server. To write an answer, only the few matching passages are sent to the AI model.

Why is it invite-only?

Atlas is new and run by one builder. The demo is open to everyone now; Pro opens to the waitlist first, before payments go live.
