Can I use Atlas for my company today?

Not yet. Atlas is invite-only while it’s in early access. The demo is open to everyone, and the waitlist hears first when Pro opens.

Could someone read a document they shouldn’t?

Every passage carries its company and departments, and the database filter runs before ranking. The AI never receives text the person can’t open, and the leak test has found 0 leaks in every run.

What happens when the answer isn’t written down?

Atlas checks that the passages it found really answer the question. If they don’t, it retries once, then says “Not found in your documents” instead of guessing.

Which files can it read?

PDF, Word, Markdown and plain text. You can see how each document was split into passages, and older versions of a document are ranked below the current one.

Does it understand Hindi?

Yes. Ask in Hindi or Hinglish and Atlas searches your documents and answers in Hindi, with the same citations.

What is in the demo?

Three made-up Indian companies with 199 documents, one-click sign-ins for every role, and a website for each with the chat bubble. The demo resets every night.
